# Appendix A: Grammar Quick Reference

## A.1 Basic Sentence Patterns

| Pattern | Example |
|---|---|
| Subject + Verb | Birds fly. |
| Subject + Verb + Object | She reads books. |
| Subject + Linking Verb + Complement | He is confident. |
| Subject + Verb + Indirect Object + Direct Object | I sent her an email. |

## A.2 Tense Structure Chart

| Tense | Affirmative structure |
|---|---|
| Simple Present | S + V1(s/es) |
| Present Continuous | S + am/is/are + V-ing |
| Present Perfect | S + has/have + V3 |
| Present Perfect Continuous | S + has/have been + V-ing |
| Simple Past | S + V2 |
| Past Continuous | S + was/were + V-ing |
| Past Perfect | S + had + V3 |
| Past Perfect Continuous | S + had been + V-ing |
| Future Simple | S + will + V1 |
| Future Continuous | S + will be + V-ing |
| Future Perfect | S + will have + V3 |
| Future Perfect Continuous | S + will have been + V-ing |

## A.3 Subject-Verb Agreement

- Singular subject takes singular verb: **The student writes.**
- Plural subject takes plural verb: **The students write.**
- **Each/every/everyone/someone** normally takes a singular verb.
- With **either...or / neither...nor**, the verb often agrees with the nearer subject.
- Uncountable nouns such as information, advice and furniture take singular verbs.

## A.4 Articles

- **a** before a consonant sound: a university, a book
- **an** before a vowel sound: an hour, an idea
- **the** for something specific or unique in context
- no article for general plural/uncountable meaning: Books help us. Knowledge matters.

## A.5 Common Prepositions

- time: at 5, on Monday, in July
- place: at the gate, on the desk, in the room
- movement: to Delhi, into the room, across the road
- method: by bus, with a pen, through practice

## A.6 Modal Pattern

> Subject + modal + V1

can = ability; may = permission/possibility; should = advice; must = strong obligation; might = uncertain possibility; would = polite request/preference.

## A.7 Punctuation

- Full stop ends a statement.
- Question mark ends a direct question.
- Comma separates list items and some clauses.
- Apostrophe shows possession or contraction.
- Colon introduces a list or explanation.
- Semicolon connects closely related independent clauses.

## A.8 Frequently Confused Words

| Word 1 | Word 2 |
|---|---|
| affect = influence | effect = result |
| advice = noun | advise = verb |
| accept = receive | except = excluding |
| loose = not tight | lose = fail to keep |
| principal = main/head | principle = rule |
| their = belonging to them | there = place / they're = they are |
